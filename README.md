## 📂 檔案清單與使用方式

本專案提供兩種 16:9 格式的專業簡報：

### 1. 互動式網頁簡報 (`index.html`)
- **檔案路徑：** `index.html`
- **最新優化：**
  - 移除每頁底部重複的藍色訊息框，釋放垂直閱讀空間。
  - 所有核心提示（如 💡 核心提醒、⚠️ 緊急警訊）皆直接內嵌於投影片主體卡片內，一氣呵成。
- **快速開啟指令 (macOS)：**
  ```bash
  open index.html
  ```

#### 鍵盤快捷操作：
| 按鍵 | 功能說明 |
| :--- | :--- |
| `→` / `Space` / `PageDown` | 下一張投影片 |
| `←` / `PageUp` | 上一張投影片 |
| `Home` / `End` | 跳至首頁 / 結尾頁 |
| `F` | 切換 **全螢幕簡報模式** |
| `M` | 開啟／關閉 **43 頁目錄跳轉抽屜** |
| `P` | 開啟列印對話框（可一鍵匯出為 **16:9 橫向 PDF 講義**） |
| `Esc` | 關閉目錄抽屜 |
